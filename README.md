# Remotejobb: Sök jobb i Sverige

Hitta lediga jobb i hela Sverige direkt i Claude. Beskriv vad du letar efter med egna ord, så söker Claude bland aktuella platsannonser och visar jobben som passar dig.

Sök på yrke, titel eller kompetens, till exempel utvecklare, sjuksköterska, lärare, säljare, ekonom, projektledare, ingenjör eller kundtjänst. Välj en stad som Stockholm, Göteborg, Malmö, Uppsala eller Linköping, eller sök jobb du kan göra hemifrån: distansjobb och hybridjobb.

Filtrera på heltid, deltid, visstid, konsultuppdrag eller praktik, på lägsta månadslön och på hur nyligen jobbet publicerades. Du kan också se alla lediga jobb hos ett visst företag eller inom en kategori som IT, ekonomi, vård, utbildning, marknadsföring eller HR.

Öppna ett jobb för att läsa hela annonsen, med arbetsuppgifter, krav, lön, sista ansökningsdag och länk till ansökan. Be Claude sammanfatta kraven, jämföra flera tjänster eller hitta liknande jobb.

Nya jobb läggs till varje dag. Fungerar på svenska och engelska.

Testa att fråga:
- "Hitta deltidsjobb inom kundtjänst som jag kan göra hemifrån"
- "Vilka IT-jobb i Göteborg har publicerats den här veckan?"
- "Visa heltidsjobb som ekonom i Stockholm"
- "Sammanfatta kraven för det första jobbet och ge mig ansökningslänken"

## Vad som skickas och vart

Pluginet ansluter till en enda server, `https://remotejobb.se/mcp`. Claude skickar det som behövs för sökningen, till exempel sökord, filter och jobb-id. Ingen inloggning eller nyckel behövs, och pluginet kör inga skript eller program på din dator.
